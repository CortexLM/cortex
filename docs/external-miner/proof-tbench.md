# Historical Proof topic guide

This page preserves an old link. It does not identify a live topic, supported
benchmark, runner or model. The previous topic-specific instructions are not
the Python Proof contract.

Proof topics are dynamic, operator-published signed documents. Discover their
current ids through `GET /challenge/proof/v1/proof/topics`, then read the
selected document's rules, artifact requirements, BYOK variables,
documentation and endpoints. Only an open topic in its active epoch window is
eligible for submission.

Use the [Proof miner guide](proof.md) for the Python CLI and API. Do not submit
to a historical id or assume that an old result establishes current scoring
availability or on-chain payment.
