# Archived local testnet runbook

This path remains for links in the frozen Design specification. The Rust
services, deployment overlays and local testnet scripts described here are
retired and cannot run the Python subnet.

Use the [Python deployment guide](../../deploy/README.md) for master, validator
and dedicated KVM-host setup, and the [trust-root ceremony](../how-to/trust-root.md)
for signing keys and trust documents. The [validator guide](../external-miner/validators.md)
describes independent sealed-bundle verification and chain submission.

Offline reward-path tests, a live model test and a KVM lifecycle test establish
different properties. None alone establishes a confirmed on-chain payment.
